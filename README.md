# sehir_kesif

A new Flutter project.

## Google Places API — maliyet uyarısı (geliştiriciler)

`mass_enrich_city.py` ve toplu içerik scriptleri **Text Search + Place Details** ile çok sayıda istek yapar; çok şehir çalıştırmak **binlerce TL** seviyesinde Cloud faturası üretebilir. Script, çalışmadan önce **`I_ACCEPT_GOOGLE_PLACES_BILLING_RISK=1`** ortam değişkeni veya **`--i-accept-billing-risk`** bayrağı istemezse çıkar — bodoslama koşturmayın. Önce tek şehirle deneyin. [Maps Platform fiyatlandırması](https://mapsplatform.google.com/pricing/).
